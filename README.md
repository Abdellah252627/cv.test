# السيرة الذاتية - عبدالله محميتي

موقع سيرة ذاتية احترافي وعصمي مبني بـ HTML و CSS و JavaScript خالص، لعرض المهارات والخبرات ومحفظة الأعمال ومعلومات التواصل.

## ✨ المميزات

- 🎨 تصميم عصري ومتجاوب مع جميع أحجام الشاشات
- 🌙 وضع ليلي/نهاري مع حفظ التفضيل تلقائياً
- ⬆️ زر التمرير للأعلى يظهر عند النزول بالصفحة
- ✅ تحقق من صحة نموذج التواصل قبل الإرسال
- 🖨️ تنسيق خاص للطباعة
- 🚀 بدون أي مكتبات خارجية (Zero Dependencies)

## 🚀 طريقة الاستخدام

### التشغيل المحلي

افتح ملف `cv.html` مباشرة في المتصفح، أو استخدم خادماً محلياً:

```bash
# باستخدام Python
python -m http.server 8000

# أو باستخدام Node.js
npx serve
```

ثم توجه إلى `http://localhost:8000`
